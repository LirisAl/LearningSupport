# LearningSupport

Программа для обучения Java.

## Описание
Консольное приложение с меню для различных учебных задач. В настоящий момент реализован следующий функционал:
1. Рандомайзер;
2. Информация о локальной дате и времени;
3. ~~Информация о погоде в регионе;~~ `в разработке`

## Как запустить
1. Откройте проект в IntelliJ IDEA/любом другом IDE или через консоль.
2. Запустите класс Support.java.

## Структура проекта
- `Support.java` - главный класс с меню.
